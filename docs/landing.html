// 工作流程

从开口到上屏，一气呵成

没有要记的快捷键组合，没有要切换的窗口。只有“按住”和“松开”。

01

按住右 Ctrl

焦点在任意输入框时按住，屏幕中下方浮现语音胶囊。

02

自然说话

Silero VAD 实时切分语音段，后台逐段转写，胶囊里滚动显示预览。

03

松开按键

只需完成最后一段的转写，再把各段文本合并成完整的一句话。

04

文字上屏

经 Fcitx5 提交到刚才的输入框，和拼音打出来的字没有区别。

右 Ctrl按住键盘说话 · 任何会话可用
在输入框长按左键 · 约半秒后开始，X11 会话

// 快速开始

三分钟，开始用嘴打字

  1. 01

    下载安装包

    从 GitHub Releases 下载最新的 echoflow_*.deb。

  2. 02

    安装并重载 Fcitx5

    安装后在当前用户会话里执行一次 fcitx5 -rd，让插件生效。

  3. 03

    下载模型，开口

    跟随首次运行引导下载 Qwen3-ASR，之后按住右 Ctrl 就能说话。

  1. 01

    准备环境

    deepin 25 或兼容发行版，安装 Fcitx5 与 PipeWire。

  2. 02

    构建并安装

    递归克隆子模块后用 CMake 构建，安装脚本会启用用户服务并重载 Fcitx5。

  3. 03

    下载模型，开口

    托盘 → 设置 → 模型，下载后按住右 Ctrl 即可。

bash — echoflow
# 从 Releases 下载最新安装包后
$ sudo apt install ./echoflow_*.deb
$ fcitx5 -rd

# 打开托盘 → 设置 → 模型，下载 Qwen3-ASR
# 然后：按住右 Ctrl，说话，松开 ✨
$ git clone --recurse-submodules https://github.com/hualet/echoflow.git
$ cd echoflow
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
$ cmake --build build
$ ./install-user.sh

# 已启用 echoflow.service 与 echoflow-ui.service
# 已重载 Fcitx5 —— 下载模型后按住右 Ctrl 开始
